# دليل التثبيت وأول تشغيل — مخبز الولاء الحديث

## 1) التثبيت على Windows

### الخيار أ: الحزمة المحمولة (الجاهزة الآن)
1. انسخ ملف `Alwalea Modern Bakery-1.0.0-win.zip` من مجلد `release/` إلى جهاز المخبز.
2. انقر زرًا أيمنًا ← **استخراج الكل** إلى مجلد مثل `C:\AlWaleaBakery`.
3. شغّل `Alwalea Modern Bakery.exe` من داخل المجلد.
4. أنشئ اختصارًا لسطح المكتب: زر أيمن على الملف ← **إرسال إلى** ← **سطح المكتب**.

> ⚠️ هذه الحزمة أُعدت و**لم تُختبر بعد على Windows** — عند أول تشغيل قد يظهر تحذير SmartScreen لأن التطبيق غير موقّع رقميًا: اختر **More info ← Run anyway**. راجع `decisions.md` بشأن توقيع التطبيق.

### الخيار ب: المثبّت NSIS (يُبنى من جهاز Windows)
اتبع `build-from-source.md` على جهاز Windows لإنتاج `AlWaleaModernBakery-Setup-1.0.0.exe` ثم:
1. شغّل المثبّت واختر مجلد التثبيت (الافتراضي مناسب).
2. ستُنشأ اختصارات قائمة ابدأ وسطح المكتب.
3. إلغاء التثبيت من إعدادات Windows ← التطبيقات — **لا يحذف بيانات النشاط** الموجودة في `%APPDATA%\alwalea-modern-bakery`.

## 2) أول تشغيل — معالج الإعداد
عند أول فتح يظهر معالج من ثلاث خطوات:
1. **بيانات النشاط**: اسم النشاط (الافتراضي «مخبز الولاء الحديث» وقابل للتعديل)، اسم المالك، الهاتف والعنوان (اختياري).
2. **العملة**: الشيكل ₪ افتراضيًا (أو حسب اختيارك). الضريبة معطلة افتراضيًا.
3. **كلمة المرور**: افتراضيًا `1234` (4 أحرف/أرقام على الأقل) — غيّرها من **الإعدادات ← تغيير كلمة المرور** بعد أول دخول.

> الدخول لاحقًا بكلمة المرور فقط (وضع الحساب الواحد — الجلسة تُربط بحساب المالك تلقائيًا).
> كلمة المرور تُخزَّن مُلبَّدة (scrypt + salt مستقل) ولا يمكن استرجاعها — احفظها جيدًا.
> بعد تغييرها توقف الكلمة القديمة عن العمل فورًا ولا يوجد بديل احتياطي.

## 3) بعد الدخول — خطوات البداية المقترحة
1. **الإعدادات ← المستخدمون**: أنشئ حسابات العاملين (كاشير، مخزون…) بدور لكل واحد.
2. **المنتجات**: أضف التصنيفات ثم المنتجات والمواد الخام (نوع: مادة خام / منتج مصنّع / بضاعة تجارية).
3. **المخزون ← رصيد افتتاحي**: سجّل الكميات الموجودة فعليًا في المخبز مع التكلفة.
4. **العملاء والموردون**: أضف الملفات وحدد حدود ائتمان عند الحاجة.
5. **الخزينة**: افتح وردية برصيد افتتاحي قبل أول بيع نقدي.
6. جرّب **نقطة البيع**: أضف منتجًا للسلة واضغط **F4** أو زر الترحيل، ثم اطبع الإيصال.

## 4) اختصارات مفيدة
| الاختصار | الوظيفة |
|---|---|
| F2 | التركيز على بحث نقطة البيع |
| F4 | ترحيل فاتورة البيع |
| Esc | إغلاق النوافذ المنبثقة |

## 5) متطلبات التشغيل
- Windows 10/11 (64 بت) بدقة 1366×768 فأكثر.
- لا حاجة للإنترنت إطلاقًا — كل شيء محلي.
- الطابعة الحرارية: أي طابعة مثبتة في Windows للعرض 58/80 مم (حدد العرض من الإعدادات ← البيع والفاتورة؛ تُطبع الإيصالات عبر نافذة الطباعة العادية).
