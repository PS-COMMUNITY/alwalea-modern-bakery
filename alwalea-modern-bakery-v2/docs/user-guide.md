# دليل الاستخدام الأساسي — مخبز الولاء الحديث

الواجهة عربية بالكامل، القائمة على اليمين، والاسم الظاهر في الترويسة والإيصالات يأتي من الإعدادات ديناميكيًا.

## الأدوار والصلاحيات
| الدور | يستطيع |
|---|---|
| المالك | كل شيء |
| المدير | كل شيء عدا إدارة المستخدمين والنسخ الاحتياطي |
| كاشير | نقطة البيع، فواتيره، تحصيل العملاء، الوردية |
| مسؤول المخزون | الكتالوج والمخزون (افتتاحي/جرد/إعدام) وعرض المشتريات |
| مسؤول الإنتاج | الوصفات ودفعات الإنتاج |
| مسؤول التوزيع | المندوبون والجولات والتسوية |
| المحاسب | التقارير المالية، المصروفات، التحصيل، سجل التدقيق |

الصلاحيات مفروضة في الخدمة نفسها — إخفاء الزر في الواجهة ليس الحماية الوحيدة.

## نقطة البيع (الشاشة الأسرع)
1. ابحث بالاسم/الكود/الباركود أو اضغط **F2**.
2. اضغط بطاقة المنتج لإضافتها؛ عدّل الكمية والسعر وخصم السطر من السلة.
3. اختر عميلًا إن كان البيع آجلًا (إلزامي بحسب الإعداد)، وحدد نمط الدفع: نقدي كامل / جزئي / آجل.
4. **F4** أو زر الترحيل — تُنشأ الفاتورة ذريًا: بنود + مخزون + دفتر عميل + صندوق معًا.
5. تظهر نافذة الإيصال الحراري (80مم افتراضيًا) — اضغط **طباعة** أو **لاحقًا**.
- المبيعات الآجلة تحتسب حد الائتمان للعميل تلقائيًا وترفض تجاوزه.
- إعادة ترحيل بنفس العملية (نقر مزدوج) مستحيلة: حارس + معرف فريد لكل محاولة.

## العملاء والديون
- ملف كل عميل: بيانات + حد ائتماني + نوع سعر (تجزئة/جملة).
- **كشف الحساب**: قيود الفواتير والمدفوعات والتسويات مع رصيد متجمع.
- **تسجيل دفعة**: جزئية أو كاملة — تنعكس فورًا في الكشف والصندوق والتقارير.
- الرصيد السالب يعني «دفع مقدَّم» (عميل له رصيد عندك).

## المشتريات والموردون
- فاتورة شراء: مورد + بنود بتكلفة الوحدة + دفعات (نقدية/آجلة).
- تكلفة المنتج تُحدَّث **بمتوسط مرجح** تلقائيًا مع كل شراء.
- دفعة لاحقة على الفاتورة من شاشة تفاصيلها، وكشف حساب لكل مورد.

## المخزون
- أي تغيير رصيد يمر بحركة موثقة (شراء/بيع/إنتاج/تلف/جرد/تحميل جولة) — لا تعديل يدوي للأرصدة.
- **الجرد**: أدخل الكمية المعدودة فيولّد النظام حركة الفرق مع سبب.
- تقرير منخفض المخزون وتنبيهات في لوحة التحكم.
- المخزون السالب ممنوع افتراضيًا (يُسمح به فقط من الإعدادات ويُوثق).

## الإنتاج والوصفات
- الوصفة: مادة خام → كميات لكل دفعة → منتج ناتج.
- دفعة إنتاج: النظام يحسب المواد المطلوبة تناسبيًا وينبه إن نقصت، ثم **بضغطة واحدة**: يخصم المواد ويضيف الناتج ويحسب تكلفة المواد وتكلفة الوحدة — كل ذلك ذريًا.
- الهدر يُسجل على الدفعة ويظهر في التقارير.

## التوزيع والمندوبون
1. عرّف المندوبين وخطوط السير.
2. **جولة جديدة**: تحميل كميات من المخزون (تخرج من الرصيد إلى عهدة المندوب).
3. أثناء الجولة: سجّل المبيعات (نقدي/آجل) والمرتجعات (صالحة تعود للمخزون / تالفة تُعد هدرًا).
4. **التسوية**: يجب تسجيل كل الكميات المتبقية كمرتجعات أولًا؛ ثم تُنشأ فواتير حقيقية، والنقد ينتقل للصندوق، والآجل لديون العملاء — بلا أي تكرار.

## المصروفات والخزينة
- مصروف بتصنيف وطريقة دفع — النقدي يُخصم من الوردية.
- الوردية: رصيد افتتاحي، تتبع كل قبض وصرف، وعند الإغلاق يقارن **المتوقع بالفعلي** ويوثق الفرق.

## التقارير
12 تقريرًا بفلاتر فترة، كلها من الحركات الفعلية: مبيعات، تحصيلات، ديون، موردين، مشتريات، تقييم مخزون، إنتاج وهدر، مصروفات، صندوق، توزيع، وربح تقديري (بتعريف موثق — ليس صافي ربح محاسبيًا).

## سجل التدقيق
كل عملية حساسة مسجلة بالمستخدم والوقت: دخول فاشل، فواتير وإلغاؤات، تعديل أسعار، جرد، مستخدمون، نسخ احتياطي واستعادة. للقراءة فقط.

## الإلغاءات
لا حذف نهائي لأي فاتورة مرحّلة — الإلغاء يُنشئ **حركات عكسية موثقة** (مخزون يعود، دين يُعكس، نقدية تُرجع للوردية) مع سبب إلزامي ومستخدم.
