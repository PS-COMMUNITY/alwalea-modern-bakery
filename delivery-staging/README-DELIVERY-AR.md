## خطواتك بالترتيب (ثلاث خطوات فقط)

### 1) التجميع والتحقق من السلامة — إلزامي قبل أي استخدام
الملفان الكبيران يصلان كأجزاء Base64 (تنسيق التسليم الآمن). افتح PowerShell داخل مجلد التسليم ونفّذ:
```powershell
powershell -ExecutionPolicy Bypass -File decode-and-verify.ps1
```
السكربت تلقائيًا: يجمع الأجزاء → يفك Base64 → ينتج `bin64\setup.exe` و`bin64\portable.exe` → يقارن SHA-256 والحجم بالمانيفست.
- **النتيجة المطلوبة**: سطران أخضران `[setup.exe] OK` و`[portable.exe] OK` ثم «النتيجة: كل الملفات سليمة (OK)».
- **إن ظهر MISMATCH أو MISSING**: جزء ناقص أو تالف — أبلغ بالرقم المذكور لإعادة إرساله فقط.

### 2) التثبيت
- شغّل `bin64\setup.exe` — إن ظهر تحذير SmartScreen (لأن التطبيق غير موقّع تجاريًا): **More info ← Run anyway**.
- أو جرّب المحمولة `bin64\portable.exe` مباشرة بلا تثبيت.

### 3) الاختبار الميداني
افتح `UAT-CHECKLIST-AR.md` ونفّذ البنود بالترتيب — أهمها القسم 2 (الجرد والإقفال، الجديد في هذا الإصدار).
