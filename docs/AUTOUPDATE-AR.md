# التحديث عبر setup.exe — كيف يعمل ولماذا بياناتك آمنة

> السيناريو المطلوب: **نزّل ملف EXE الأحدث من Releases → افتحه → يكتشف النسخة الموجودة على الجهاز ويرقيها تلقائيًا.** هذا يعمل فعلًا هكذا، والتوثيق أدناه يشرح السبب التقني.

## 1) ماذا يحدث عند فتح setup.exe لنسخة أحدث؟

مثبت NSIS المولّد من electron-builder يحمل هوية ثابتة:

```yaml
# electron-builder.yml
appId: com.alwalea.bakery        # ← نفس الهوية في كل الإصدارات
productName: Alwalea Modern Bakery
nsis:
  oneClick: false                 # معالج معاين — ترى ماذا سيرقى
  perMachine: false               # لا يحتاج صلاحيات مدير
  allowToChangeInstallationDirectory: true
  createDesktopShortcut: always
```

عند التشغيل فوق نسخة مثبتة:
1. NSIS يجد التثبيت المسجل لنفس `appId` في سجل Windows.
2. يقترح **الترقية في المكان نفسه** (نفس مجلد التثبيت والاختصارات).
3. يستبدل ملفات التطبيق فقط — ويحافظ على إعدادات التثبيت.

## 2) لماذا البيانات لا تُمس أبدًا؟

القاعدة تُخزّن **خارج مجلد التثبيت عمدًا**:

```
%APPDATA%\alwalea-modern-bakery\
├── bakery.db                  ← القاعدة (حفظ ذري بعد كل معاملة)
└── backups\                   ← النسخ التلقائية واليدوية
```

- **التحديث:** يكتب في مجلد التثبيت فقط — `%APPDATA%` لا يُفتح أصلًا.
- **إلغاء التثبيت نفسه:** لا يحذف `%APPDATA%\alwalea-modern-bakery` (موثق في `docs/build-from-source.md`).
- قبل أي استعادة نسخة داخل التطبيق: تُنشأ **نسخة أمان** تلقائيًا أولًا.

## 3) سير التحديث الموصى به

```text
1. Releases → نزّل "Alwalea Modern Bakery-X.Y.Z-setup.exe"
2. (اختياري) تحقق SHA256 مقابل SHASUMS256.txt المرفق
3. أغلق التطبيق إن كان شغالًا (النسخ التلقائية عند الإغلاق تُخلق هنا)
4. افتح setup.exe → التالي → التالي → يترقّى في مكانه
5. افتح التطبيق — بياناتك كما تركتها بالضبط
```

> **ملاحظة تشغيلية للمخبز:** لا حاجة لأي خطوة إضافية أو نقل ملفات — التحديث يترك القاعدة والنسخ الاحتياطية وسجل التدقيق كما هي.

## 4) المستقبل: فحص تحديث تلقائي من داخل التطبيق

البنية جاهزة لإضافة `electron-updater` (فحص GitHub Releases عند الإقلاع + تنزيل صامت + تثبيت عند الإغلاق). لم يُفعّل بعد عمدًا: صاحب المخبز يفضل أن تكون كل ترقية **قراءة مرئية** يوافق عليها عبر المعالج، مع بصمة SHA256 تُفحص يدويًا عند الحاجة. قرار موثق — راجع `docs/decisions.md`.
