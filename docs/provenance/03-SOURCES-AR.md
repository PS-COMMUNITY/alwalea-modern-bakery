## 🔒 ملاحظة خصوصية مهمة

- **ما لا يُرفع لهذا الريبو العام عمدًا:** سجل العمل الموحد الكامل (يحتوي روابط نفق وتوكنات)، لقطات قاعدة بيانات المالك الحقيقية، محتوى جلسات النفق، ملفات `session.txt` — كلها تبقى لدى فريق التطوير، وأُجري فحص أسرار صريح قبل النشر (D-047).
- **ما يُرفع:** الكود النظيف، الوثائق، الإصدارات بأصولها وبصماتها، ووثائق المصدر هذه (بلا أي قيمة سرية فيها).
