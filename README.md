## ✨ المزايا الكاملة

| المجال | التفاصيل |
|---|---|
| 🖥️ **نقاط البيع (POS)** | بيع نقدي وآجل، **دفع جزئي مع قيد تلقائي للمتبقي في دفتر العميل**، خصم بند/فاتورة، بحث فوري (p95 ≈ 9ms على 2000 منتج)، إيصال حراري 80مم، ترحيل بـF4، باركود Code 39 |
| 📦 **المخزون** | أرصدة لحظية، حركات موثقة المصدر، افتتاحي/جرد/إعدام بأسباب إلزامية، حد أدنى مع تنبيهات حمراء، **تسوية الجرد عبر 8 قنوات موحدة بقفل موحد يغلق ثغرات البيع أثناء الجرد** |
| 🏭 **الإنتاج** | وصفات بمكونات ونسب، أوامر إنتاج بحماية تكرار (`clientRef` فريد)، خصم المواد تلقائيًا بالتكلفة الفعلية، إضافة الناتج للمخزون |
| 🚚 **التوزيع** | جولات بمندوب ومركبة، تحميل/إرجاع، تحصيل نقدي أثناء الجولة، مطابقة المردود مع المخزون |
| 👥 **العملاء والموردون** | كشوف حساب كاملة، حدود ائتمان، دفتر ديون بتحصيلات جزئية، أرصدة افتتاحية |
| 💰 **المالية** | درج نقدي لكل وردية (افتتاح/إغلاق/فروقات)، مصروفات بتصنيفات، قيود مزدوجة مبسطة، **حسابات الأموال بأعداد صحيحة (ملّي-وحدات) — صفر أرقام عشرية** |
| 📊 **التقارير** | 11+ تبويبًا: مبيعات/ديون/تحصيلات/مصروفات/إنتاج/توزيع/جرد/تدقيق/لوحة متقدمة بمخطط شهري ومقارنات وأفضل المنتجات وأكثر المدينين — تصدير **CSV / Excel (exceljs) / PDF (طباعة)** |
| 🌙 **إغلاق الفترات** | ورقة نهاية اليوم A4 جاهزة للطباعة، إغلاق شهري بقفل حماية، عدادات مالية محمية من التعديل الرجعي |
| 🔐 **الأمان** | scrypt (N=16384) + salt مستقل، 7 أدوار صلاحيات (مالك/مدير/كاشير/مخزون/إنتاج/توزيع/محاسب) مفروضة في **طبقة الخدمة** لا إخفاء أزرار، سجل تدقيق كامل (LOGIN/SALE_CANCEL/USER_UPDATE/…) |
| 💾 **بيانات لا تُفقد** | حفظ ذري (ملف مؤقت + استبدال) بعد كل معاملة، نسخ تلقائي عند الإغلاق + نسخة أمان قبل أي استعادة، استعادة بمعاملة واحدة مع فحص سلامة مسبق، القاعدة **خارج مجلد التثبيت** — التحديث لا يمس البيانات أبدًا |
| 📡 **تيليجرام (اختياري)** | ملخص يومي تلقائي وقت محدد + زر اختبار + تحقق صيغة التوكن |
| 🌍 **واجهة** | عربية RTL كاملة، خط Cairo مضمّن محليًا، هوية بصرية كاكاو/كريم/نحاسي، تجاوب حتى 1366×768 وأهداف لمس ≥44px |

**لماذا sql.js (WASM)؟** لا وحدات native تعيد بناءها مع كل إصدار Electron — نفس SQLite مترجم WASM، تغليف مضمون عبر المنصات، وحفظ ذري بعد كل معاملة كتابية. (التفاصيل الكاملة في [`docs/decisions.md`](docs/decisions.md))

## 📥 التثبيت والتحديث (Windows)

### تثبيت جديد
1. افتح [أحدث إصدار (Releases)](../../releases) ونزّل **`Alwalea Modern Bakery-1.0.0-rc.11-setup.exe`**
2. شغّله — معالج تثبيت عادي (لا يحتاج صلاحيات مدير) + اختصار على سطح المكتب
3. أكمل معالج الإعداد الأول (اسم المحل + حساب المالك) وابدأ العمل

### التحديث إلى نسخة أحدث ⭐
> **نزّل `setup.exe` الجديد وافتحه — سيكتشف النسخة المثبتة تلقائيًا ويرقيها في مكانها، وبياناتك في `%APPDATA%\alwalea-modern-bakery` تبقى كما هي تمامًا (خارج مجلد التثبيت).**

- نفس `appId` (`com.alwalea.bakery`) يعني: النسخة الجديدة **تحل محل القديمة** باختصاراتها وإعداداتها
- القاعدة والنسخ الاحتياطية **لا تُمس** — إلغاء التثبيت نفسه لا يحذفها
- تحقق إضافي اختياري: قارن بصمة SHA256 مع `SHASUMS256.txt` المرفق بكل إصدار

<details>
<summary><b>🔒 كيف تتحقق من سلامة الملف قبل التشغيل؟</b></summary>

```powershell
Get-FileHash "Alwalea Modern Bakery-1.0.0-rc.11-setup.exe" -Algorithm SHA256
# قارن الناتج مع السطر المقابل في SHASUMS256.txt داخل الإصدار
```
</details>
